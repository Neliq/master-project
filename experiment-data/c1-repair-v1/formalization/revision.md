# Formalization revision v2

This revision preserves the original 62 patterns, 186 conditions, and every original formula. It changes the application protocol only.

## Review semantics

1. Make a provisional evidence-only judgment before reading formal cards.
2. Use formal cards to verify, challenge, and explain the provisional judgment.
3. Do not replace a provisional binary judgment merely because a formal atom is unobservable. Record UNKNOWN for that atom.
4. A complete formal trigger can upgrade a provisional negative. Direct counterevidence can downgrade a provisional positive.
5. For qualitative relations (`\gg`, `\ll`, `\approx`, `\propto`), a direct same-interface comparison is valid when both operands and direction are explicitly observed. Never invent numeric values.
6. For explicit threshold relations, require the stated measurement or mark UNKNOWN.
7. Pattern routing is an efficiency aid, not an exclusion rule. A candidate screen of NO_MATCH/UNKNOWN cannot by itself force BENIGN.

This is a development revision and must be evaluated on fresh data before any confirmatory use.
