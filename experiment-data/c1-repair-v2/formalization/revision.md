# Formalization revision v3

This revision preserves the original 62 patterns, 186 conditions, and every original formula. It changes application semantics only.

## Changes from v2

1. Every card has a hard domain/context gate: a card cannot be applied to a semantically related but structurally different interface. A reward/play loop is not a scroll/feed append mechanism; a permission overlay is not a pricing or account-deletion mechanism.
2. A qualitative relation (`\gg`, `\ll`, `\approx`, `\propto`) may be satisfied by a direct same-interface comparison when both operands and direction are observed. Numeric values must not be invented.
3. A complete visible assigned scope can support an absence predicate. Absence in an omitted or partial scope remains UNKNOWN.
4. C1 first makes an evidence-only provisional judgment. Formal review can upgrade on complete proof or downgrade on direct contradiction/core-context failure; missing secondary measurements alone cannot overwrite the provisional binary decision.

This is a bounded development revision, not a confirmatory claim.
